# Pagine da condividere

Sito statico in HTML pubblicabile con GitHub Pages. La home (`index.html`) raccoglie i collegamenti alle singole pagine interattive, ospitate nella cartella `pagine/`.

## Pubblicazione con GitHub Pages

Nel repository, apri **Settings → Pages** e scegli **Deploy from a branch**, quindi seleziona il branch `main` e la cartella `/ (root)`. Dopo il salvataggio, GitHub pubblicherà la home e i file HTML presenti nel repository.

- Home: `https://marcorzzn.github.io/ilTabellone/`
- Prima pagina: `https://marcorzzn.github.io/ilTabellone/pagine/il-tabellone-giovanni-manna.html`

Per aggiungere una nuova pagina, aggiungi il relativo file HTML in `pagine/` e inserisci un collegamento alla pagina in `index.html`. Le valutazioni del tabellone vengono memorizzate localmente nel browser di ciascun visitatore.
